# Anaconda 常用核心命令

Anaconda 的核心命令主要围绕 **环境管理** 和 **包管理** 两方面。

## 基础命令

| 操作       | 命令                                       | 说明                                |
| :--------- | :----------------------------------------- | :---------------------------------- |
| 查看版本   | `conda --version`                          | 检查 Conda 是否安装成功及其版本号。 |
| 获取帮助   | `conda --help` <br/> `conda [命令] --help` | 查看所有命令或特定命令的详细用法。  |
| 更新 Conda | `conda update conda`                       | 升级 Conda 工具本身到最新版本。     |

## 环境管理

环境管理是 Anaconda 最核心的功能，可以让你在不同项目间隔离依赖。

| 操作          | 命令                                            | 说明                                              |
| :------------ | :---------------------------------------------- | :------------------------------------------------ |
| 列出所有环境  | `conda env list` <br/> `conda info --envs`      | 查看所有虚拟环境，当前激活的环境会带有 `*` 标记。 |
| 创建环境      | `conda create -n [环境名] python=3.9`           | 创建一个新环境，建议创建时指定 Python 版本。      |
| 克隆环境      | `conda create -n [新环境名] --clone [原环境名]` | 快速复制一个已有的环境配置。                      |
| 激活/切换环境 | `conda activate [环境名]`                       | 激活并切换到指定环境。                            |
| 退出当前环境  | `conda deactivate`                              | 退出当前环境，回到 `base` 环境。                  |
| 删除环境      | `conda remove -n [环境名] --all`                | 彻底删除一个虚拟环境及其中所有包。                |

## 包管理

进入特定环境后，就可以用这些命令管理该环境下的第三方库了。

| 操作         | 命令                                  | 说明                                                  |
| :----------- | :------------------------------------ | :---------------------------------------------------- |
| 搜索包       | `conda search [包名]`                 | 查看指定包有哪些可用的版本。                          |
| 安装包       | `conda install [包名]`                | 安装一个或多个包，例如 `conda install numpy pandas`。 |
| 指定版本安装 | `conda install [包名]=[版本号]`       | 安装特定版本的包，如 `conda install numpy=1.21.0`。   |
| 从特定源安装 | `conda install -c conda-forge [包名]` | 从 `conda-forge` 等社区频道安装包。                   |
| 列出已安装包 | `conda list`                          | 查看当前环境中所有已安装的包。                        |
| 更新包       | `conda update [包名]`                 | 将指定包更新到最新版本。                              |
| 更新所有包   | `conda update --all`                  | 更新环境中的所有包。                                  |
| 删除包       | `conda remove [包名]`                 | 从当前环境中卸载一个或多个包。                        |

## 环境配置的导入导出

| 操作     | 命令                                  | 说明                                                             |
| :------- | :------------------------------------ | :--------------------------------------------------------------- |
| 导出环境 | `conda env export > environment.yml`  | 将当前环境的所有信息（包括精确版本号）导出到一个 `yaml` 文件中。 |
| 导入环境 | `conda env create -f environment.yml` | 根据 `yaml` 配置文件创建一个一模一样的新环境。                   |
